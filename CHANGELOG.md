# Changelog

## Unreleased

- Redesigned the meter screen as the spec's hybrid meter over the live camera preview (spec §4.2, §4.7): the framed scene is now the full-bleed background (rendered through `CameraPreviewView`, the one `UIViewRepresentable` wrapping `AVCaptureVideoPreviewLayer`), with a 220 pt circular EV dial and thin 6 pt state ring at center, the equivalent-exposure wheels in the lower third, the spec design tokens (dark backdrop, translucent panels, amber accent), and subtle scrims for outdoor legibility. The camera now exposes the lenses the device supplies (`CameraLens`/`CameraLensCatalog`, back position, Ultra Wide/Wide/Tele; wide preferred per FR-1) through a segmented picker, and switching lenses reconfigures the running session by replacing the video input (falling back to the previous input if the swap fails) while the engine resets its smoothing window via the normal config path. The session preset rose from VGA to 1920×1080 to support the preview. Spot metering is tap-to-position: taps are converted from screen to capture-buffer space by the new pure `SpotPointConverter` (90° CW back-camera rotation, aspect-fill crop, clamped), so the camera's `exposurePointOfInterest`, the luma Spot box, and the on-screen reticle (drawn via the inverse conversion) all land where the user pointed. `MeteringSource` gained optional `LensProviding`/`PreviewProviding` seam protocols; fixture feeds show a plain backdrop and no lens picker. Added unit tests for the screen↔capture conversion (corners, cropped top tap, round-trip, clamping, degenerate sizes) and lens preference. Preview, lens switching, and reticle placement still require physical-device validation.
- Added the real camera metering feed behind the `MeteringSource` seam. `CameraMeteringSource` runs an `AVCaptureSession` with the built-in camera, reads native auto-exposure metadata (ISO, duration, aperture) from video frames as the EV authority, and analyzes biplanar Y-planes for luminance confidence and Spot luma only. A `CameraFrameCoordinator` serializes frame processing off the session queue. Camera-usage permission is requested once at start; if it is denied or the session cannot run, the source reports `.unavailable` with a reason, the meter UI shows a "Camera unavailable" banner with an Open Settings shortcut, and permission changes are picked up automatically when the app returns to the foreground (the iOS 27 SDK removed `AVCaptureDeviceWasAuthorized`, so recovery observes `UIApplication.didBecomeActiveNotification`). The default feed is now the camera; the DEBUG test-data bar can switch to the fixture feed. `MeteringSource.applyConfiguration` is a protocol requirement so mode/Spot context reaches the concrete source, and feed swaps reset `MeterEngine` state so a new feed never serves a stale reading. Added unit coverage for the seam contract, feed switching, and the luminance analyzer (grid luma, Spot region, clamping, non-biplanar rejection). Camera, permission, and Spot behavior still require physical-device validation.
- Added the metering seam and the meter UI. `MeteringSource` is the single feed seam; the DEBUG-only `TestMeterSource` emits known fixtures at ~10 Hz with stable/unstable/dark/clipped scenarios and pause/step (spec 8.5). `ExposureState` keeps the locked/anchor/solved dial trio in equivalent exposure (spec §4.3), `MeteringController` drives the engine and holds live/held readings, and the portrait-first `MeterScreen` shows the EV readout, LIVE/HOLD state, confidence banner, lockable dials, filter compensation, stop increment, and a clearly-labeled DEBUG test-data bar. Unit coverage added for dial solving, lock/anchor behavior, hold/live freezing, and compensation re-solves. The app now shows the meter instead of the placeholder screen.
- Added the pure, deterministic meter core — `MeterSample`, `MeterReading` (with `ConfidenceLevel`), `MeterConfiguration`, `MeteringMode`/`NormalizedPoint`, and `MeterEngine` — with fixture-based Swift Testing coverage of the metadata EV authority, 10 Hz rate cap, rolling-window stability, dark/clipped confidence and precedence, Spot luma judgment, stale/unavailable handling, and context-change resets. Luminance only expresses confidence; it never alters the reported EV.
- Set the minimum deployment target to iOS 26.0 to match the spec's iOS 26+ requirement.
- Added the pure, deterministic exposure-math domain — `ExposureAxis`, `StopIncrement`, `ExposureMath`, `ExposureValueTables`, `StopQuantizer`, and `ExposureSolver` — with table-driven Swift Testing coverage of the math, stop rounding, filter compensation, and boundaries.
- Added agent delivery contract and initial project-management documentation.
